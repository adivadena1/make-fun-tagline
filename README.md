Bounty: [One Line, One Week: The make.fun Tagline](https://make.fun/bounty/u-boge-one-line-one-week-the-make-fun-tagline-66aca584)

## Run it

```sh
node main.ts
```

The program writes the tagline to `/output/entry.txt`.
